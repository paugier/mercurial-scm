# Community

Where to get help, discuss Mercurial and follow its development.

## Chat

- **Matrix** (preferred):
  [#mercurial:matrix.org](https://matrix.to/#/#mercurial:matrix.org). This is the main
  channel of the project, any Matrix client can be used to join it.
- **IRC**: `#mercurial` on [Libera.Chat](https://libera.chat/) (`irc.libera.chat`). This
  channel is unofficially bridged to the Matrix one.

## Mailing lists

| List                                          | Purpose                                      | Links                                                                                                                                                         |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <mercurial@lists.mercurial-scm.org>           | General discussion and help for users        | [subscribe](https://lists.mercurial-scm.org/mailman/listinfo/mercurial), [archives](https://lists.mercurial-scm.org/pipermail/mercurial/)                     |
| <mercurial-devel@lists.mercurial-scm.org>     | Development of Mercurial                     | [subscribe](https://lists.mercurial-scm.org/mailman/listinfo/mercurial-devel), [archives](https://lists.mercurial-scm.org/pipermail/mercurial-devel/)         |
| <mercurial-packaging@lists.mercurial-scm.org> | Coordination with the packagers of Mercurial | [subscribe](https://lists.mercurial-scm.org/mailman/listinfo/mercurial-packaging), [archives](https://lists.mercurial-scm.org/pipermail/mercurial-packaging/) |
| <mercurial-security@lists.mercurial-scm.org>  | Reporting and discussing security issues     | [information](https://lists.mercurial-scm.org/mailman/listinfo/mercurial-security)                                                                            |

The archives of `mercurial-security` are only available to its members and subscriptions
are moderated, so that security issues can be discussed privately.

The other lists are listed on <https://lists.mercurial-scm.org/>.
