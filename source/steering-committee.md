# Steering Committee

How the Mercurial project is governed.

## Purpose

The steering committee was created in 2016 to set project policy, manage project resources, and delegate access for project roles. This group legally represents the project to our parent nonprofit, the Software Freedom Conservancy and is self-selecting. It is expected that, outside of handling of access to project resources (for example, publication rights or Matrix operator status) and disbursing funds available to the project from our account at conservancy, the steering committee will have minimal need to be involved in the day to day management of Mercurial, but instead the project will be run by the community, coordinated by the committers and reviewers.
